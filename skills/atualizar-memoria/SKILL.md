# Atualizar memória

## Passos
1. Resuma a sessão em poucos pontos: o que foi feito, descoberto e decidido.
2. Proponha as alterações por arquivo, sem aplicar ainda:
   - `pesquisa/trabalho-feito.md`: nova entrada na linha do tempo
   - `pesquisa/resultados/`: novo arquivo com base em `_modelo.md`, se houve resultado
   - `pesquisa/literatura/`: novo arquivo com base em `_modelo.md`, se houve artigo
   - `pesquisa/decisoes.md`: nova decisão, se houve
   - `pesquisa/objetivos.md`: mudança de status de hipótese ou meta, se houve
3. Peça confirmação do usuário.
4. Aplique acrescentando conteúdo. Não apague nem reescreva o que já existe sem autorização.
5. Informe quais arquivos foram alterados.

## Regras
- Registre apenas o que o usuário confirmou. Não registre suposições como fatos.
- Datas no formato AAAA-MM-DD.
- Mantenha as entradas curtas e aponte para os arquivos de detalhe.
